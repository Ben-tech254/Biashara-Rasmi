# Biashara Rasmi

A campaign website encouraging Kenya's small businesses to register and go formal.

**Pages**
- `index.html`: Home (benefits, downsides of staying informal, stories, products)
- `stories.html`: Mama Peres (MitMit), Steven (Abila Peanut Butter), Albert (EldoHub)
- `steps.html`: How to register, step by step
- `facts.html`: Kenya in numbers (KNBS Economic Survey 2026)

Plain HTML, CSS and JavaScript. No build step: deploy the folder as a static site (e.g. Vercel, framework preset "Other").
